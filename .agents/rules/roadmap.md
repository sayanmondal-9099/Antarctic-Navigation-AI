# Project Roadmap

The overarching phases of the Antarctic Navigation AI project are defined as follows:

1. **Environment** (Setup and dependencies)
2. **React** (Frontend foundation)
3. **FastAPI** (Backend foundation)
4. **React ↔ FastAPI** (API integration and proxy)
5. **Map** (Leaflet map integration)
6. **Sample Antarctic data** (Local demo data setup)
7. **Iceberg layer** (Rendering iceberg data)
8. **Sea-ice layer** (Rendering sea-ice data)
9. **Ship layer** (Rendering vessels)
10. **Risk engine** (Evaluating navigation risks)
11. **A* routing** (Deterministic safe-path routing)
12. **Multi-vessel routing** (Conflict resolution and awareness)
13. **Supabase** (PostgreSQL Database, Auth)
14. **ML** (Predictive modeling and augmentation)
15. **Real data APIs** (NSIDC, Copernicus, live AIS)
16. **SOS** (Emergency monitoring)
17. **Final UI** (Polishing and command center integration)
18. **Deployment** (Production rollout)
